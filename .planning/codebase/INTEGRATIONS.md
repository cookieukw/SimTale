# Integrations

## Internal Integrations

- **Hytale Server:** The mod runs as a Hytale server-side plugin/mod.
- **Hytale Registries:** Uses Hytale's built-in registry system for components, systems, and commands.

## External Integrations

- **Caskara:** Hard dependency for database and persistence logic. The mod relies on Caskara for saving and loading NPC data.

## Environment

- **SDK Path:** `/home/cookie/Android/Sdk` (configured in local.properties)
- **Hytale Data Path:** `/home/cookie/.var/app/com.hypixel.HytaleLauncher/data/Hytale`
